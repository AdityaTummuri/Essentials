# Python Project Starter Template

A clean baseline for modern Python projects using Python 3.10+, `pyproject.toml`, and optional `ruff` / `pytest` tooling.

## Quickstart

```bash
# Set up virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install editable with dev dependencies
pip install -e ".[dev]"

# Run app
python main.py
```

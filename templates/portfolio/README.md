# Creative Web / Portfolio Starter Template

A lightweight baseline for interactive 3D portfolio websites using Vite, Three.js, and clean semantic CSS/HTML.

## Quickstart

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

Pair with the `portfolio` skills preset in Essentials:
```bash
./scripts/essentials install portfolio --target .
```
